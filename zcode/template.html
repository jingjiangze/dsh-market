数据从哪来

登记数据来自本机 ZCode 的插件目录与各市场清单：名称、版本、来源类型、sha256、静态风险（hooks / MCP / LSP / npm 安装脚本）与启用状态。生成后随仓库提交，页面不请求第三方资源。

怎么判定可安装

  • 来源类型：path（本地缓存）、builtin（随客户端下发）、zip（官方 CDN 归档）、git / github / git-subdir（远端仓库）。
  • 「可安装」按构建时的主机可达性判定；git 类源依赖 github.com，当前网络不可达时标为 blocked。
  • 安装命令走本机 plugin-on-demand 技能：先 dry-run，--yes 才写入，远端源有 4 秒预检。

边界

这是元数据登记，不是代码托管，也不背书任何插件。插件行为以包本身为准；带 hooks / MCP / 安装脚本的条目在启用前应阅读其清单。
